# The Pacific Crest Trail · เส้นทางแปซิฟิกเครสต์

https://nanobotco.github.io/pct/

One page: numbers, a south-to-north photo walk, fire/snow/flood links, notable years, towns and trail businesses for sale, traditions, Burney Mountain Guest Ranch.

Edit `tools/page.html` and `tools/traditions.html`, then `python3 tools/build.py` writes `docs/index.html`. `tools/card.html` renders `docs/card.jpg` in headless Chrome.
